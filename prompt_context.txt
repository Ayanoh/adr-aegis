  SECTION 2 — LE PROJET EN BREF
================================================================================

NOM : ADR-AEGIS
LOCALISATION : /home/m0riaty/Downloads/AI_SEC_Proj/Tache 2/adr-aegis/

C'EST QUOI (analogie) :
  Un « garde du corps » / « poste de sécurité » pour les agents IA.
  Quand une IA (ex: assistant de code, agent autonome) veut exécuter une action,
  ADR-AEGIS l'intercepte AVANT et décide : BLOCK / ASK / SANITIZE / ALLOW.
  Objectif : détecter prompt injections, jailbreaks, reverse shells, exfiltration de
  données, credentials volés, détournements d'outils (LOLBins).

BUT FINAL :
  Rivaliser avec le projet ADR d'Uber (https://github.com/uber/ADR)
  — système de sécurité pour agents IA déployé en production chez Uber
  (paper MLSys 2026). Architecture Uber ADR = 4 composants :
    1. Observability (capture des traces d'agents)
    2. Benchmark (303 tâches, 133 serveurs MCP, 17 techniques d'attaque)
    3. Detection (Tier 1 triage rapide + Tier 2 raisonnement agentique dual-agent)
    4. Prevention (bloquer avant exécution — non open-source chez Uber)

  SECTION 3 — ARCHITECTURE ACTUELLE

  aegis/core/engine.py .......... LE CHEF DE LA SÉCURITÉ (Decision Engine)
       └─ écoute tous les vigiles, fusionne les verdicts, gère l'escalade Tier 2.
          Priorité des décisions : BLOCK > ASK > SANITIZE > ALLOW
          Presets de sensibilité : PARANOID(0.70) < BALANCED(0.85) < RELAXED(0.95)

  SENSOR LAYER (aegis/sensor/) ... LE FOUILLEUR + L'OBSERVATEUR
       ├─ decoders.py ... désembuage récursif (Base64 imbriqué, Hex, ROT13, homoglyphes, URL-encoding)
       └─ extractors.py . extraction d'IPs, URLs, commandes shell, chemins de fichiers, tokens

  TIER 1 - FAST (~5-15ms) (aegis/tier1_fast/) ... LES VIGILES RAPIDES
       ├─ heuristics.py .......... catalogue de 1 803 règles YAML (ADR + Sage + Sigma MITRE ATT&CK)
       ├─ secrets_scanner.py ..... scanner de 210 patterns (20 natifs + 190 Gitleaks, entropie Shannon)
       ├─ ml_classifier.py ....... modèle ProtectAI/deberta-v3 (prompt injection, 100% précision)
       ├─ jailbreak_classifier.py  modèle Meta Prompt-Guard-86M avec auto-vérification canary check
       ├─ vector_matcher.py ...... similarité sémantique vectorielle via ChromaDB (70 patterns, 100% précision)
       └─ known_attacks.py ....... 70 patterns d'attaques curés (prompt injection, jailbreak, reverse shell, etc.)

  TIER 2 - DEEP (~2-10s) (aegis/tier2_deep/) ... L'ENQUÊTEUR SENIOR COGNITIF
       ├─ llm_provider.py ........ abstraction LLM (GeminiProvider via urllib stdlib, MockLLMProvider)
       ├─ prompts.py ............. prompts spécialisés Forensic + Critic (invariant: 0 fuite de secret)

  DAEMON & INTERCEPTION (aegis/daemon/) ... LE GARDE DU CORPS ACTIF (MODE DAEMON)
